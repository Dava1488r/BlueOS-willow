# Персонаж, звуки и обои — свои файлы

В исходниках BlueOS **нет файлов из Blue Archive**: моделей персонажей, голосов, звуков, музыки и картинок из игры.
Это чужая собственность (Nexon / Yostar), выкладывать её нельзя. Без них BlueOS работает полностью — нет только
того, что из них сделано. Если у вас есть своя копия игры и вы хотите вернуть всё для себя, положите файлы в одну
папку и запустите скрипт — сборка сама их подхватит. **Не выкладывайте и не раздавайте получившиеся сборки и файлы.**

## Что без файлов
| Без файлов | С файлами |
|---|---|
| Экран блокировки без персонажа (часы, нимб, приветствие, погода, AOD — есть) | Арона или Плана на экране блокировки и в AOD, реагирует на касания, наклон, тряску, говорит своим голосом |
| Нет виджета «Персонаж» и страницы «Персонаж» в «Обоях и стиле» | Виджет с ней на рабочем столе, парта, реплики |
| Звонок, уведомления, будильник, звуки зарядки — стандартные LineageOS; звуки блокировки — «Старт», «Огонь» и «Android» | Музыка и звуки из игры (MomoTalk и др.) — по умолчанию и в списках звуков, остальные звуки блокировки |
| Обои — стандартные LineageOS | Свой набор «BlueOS» в «Обоях и стиле» и обои по умолчанию |
| Анимация загрузки BlueOS (нимб + надпись) | плюс «классические» анимации на выбор |

## Как добавить
1. Соберите папку (назовём её `assets/`) — нужны только те части, что хотите вернуть:
```
assets/
  characters/arona/spine/   arona_spr.skel  arona_spr.atlas  arona_spr.png      ← Арона (Spine 4.2)
  characters/arona/voice/   *.ogg   (реплики, имена как на вики без префикса персонажа: Work_In_1.ogg …)
  characters/arona/sfx/     SFX_Emoticon_Motion_*.wav   (звуки эмоций)
  characters/arona/desk/    arona_desk.skel  arona_desk.atlas  arona_desk.png   ← Арона за партой (см. ниже)
  characters/plana/spine/   NP0035_spr.skel  NP0035_spr.atlas  NP0035_spr.png  ← Плана
  characters/plana/voice/   *.ogg
  notification/  clockAlarm/  "Unlock, lock"/  touch/   ← звуки (любой формат, который читает ffmpeg)
  boot/bootanimation/light/bootanimation.zip  boot/bootanimation/dark/bootanimation.zip   ← свои анимации загрузки
  wallpaper/     *.jpg / *.png                                    ← свои обои (файл «25.*» станет обоями по умолчанию)
  stickers/      arona.png                                        ← стикер для фото-виджета Галереи
```
   Точные имена всех файлов, которые использует BlueOS, с контрольными суммами — в [ASSETS-files.txt](ASSETS-files.txt).
   Голоса с другими именами просто не прозвучат; модели должны называться ровно так.
2. Запустите из корня исходников (нужны `python3-pil` и `ffmpeg`):
```
python3 vendor/blueos/tools/import-assets.py /путь/к/assets
```
   Он раскладывает файлы по `vendor/blueos/media/` и оверлеям обоев. Части, которых нет, пропускает.
3. Пересоберите (`m bacon`). Первая сборка после добавления файлов дольше обычного — это нормально.
4. Проверьте на телефоне: `adb shell ls /product/media/blueos/spine/arona` — три файла модели;
   в «Обоях и стиле» появилась страница «Персонаж».

## Откуда файлы
Это файлы самой игры (Unity): модели Spine 4.2 из анимаций лобби/персонажей (`arona_spr`, `NP0035_spr`), сцена
кабинета `Arona_workpage_daytime` (из неё парта), голоса персонажей, звуки интерфейса и эмоций, музыкальные темы.
Достают их из **своей** установленной копии игры утилитами для распаковки Unity-ассетов. Ссылок на готовые сборники
чужих файлов мы не даём.

**Парта:** сцена кабинета огромная (весь класс, ~32 МБ в памяти), из неё нужна только Арона за партой:
```
python3 vendor/blueos/tools/cut-workpage.py <папка со сценой Arona_workpage_daytime> assets/characters/arona/desk
```

## Звуки по умолчанию
По умолчанию звонок, уведомление, будильник, звуки зарядки и касания — стандартные LineageOS, звук
блокировки и разблокировки — «Старт» (он есть в исходниках). Добавленные звуки появляются в списках
«Настройки» → «Звук» (мелодия, уведомление, будильник, «Звуки зарядки», «Звук блокировки экрана», «Звук касания»),
выбрать их можно там.
