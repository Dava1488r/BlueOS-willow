# Установка готовой BlueOS на Redmi Note 8 / Redmi Note 8T

[English](INSTALL-RedmiNote8T.md) | **Русский**

Эта инструкция и архив предназначены для **Redmi Note 8T** (`willow`) и **Redmi Note 8** (`ginkgo`); готовая сборка находится на вкладке **Releases** (`v0.8.1-willow`).

### Совместимость моделей:

| Модель | Кодовое имя | Особенности | Поддержка |
|---|---|---|---|
| **Redmi Note 8T** | `willow` | Есть NFC (NXP PN553) | ✅ Полная |
| **Redmi Note 8** | `ginkgo` | Без NFC | ✅ Полная |

Прошивка построена на базе **LineageOS 24.0 (Android 17)** со встроенным слоем BlueOS (часы с живым нимбом, виджеты Blue Archive, библиотека Arona, анимации и звуки).

---

## ⚠️ Прочитайте до начала
- **Разблокированный загрузчик:** Обязателен. Разблокировка загрузчика через Mi Flash Unlock стирает все данные с телефона.
- **Обязательный бэкап EFS и Persist:** Перед первой установкой в рекавери обязательно сделайте бэкап разделов **EFS** и **Persist** на MicroSD или компьютер. В них содержатся калибровки радиомодуля, Wi-Fi MAC и IMEI.
- **Все данные на телефоне сотрутся:** Сделайте бэкап важных файлов и 2FA кодов перед переходом с MIUI или другой AOSP-прошивки.
- **Персонаж и звуки:** В соответствии с лицензией, прошивка не содержит закрытых игровых файлов Nexon/Yostar. Вы можете добавить персонажа (Арона / Плана) в один клик прямо на телефоне: *«Обои и стиль» → «Персонаж» → «Добавить файлы персонажа»* ([ASSETS.ru.md](ASSETS.ru.md)).
- **Google Play:** Включен в сборку (MindTheGapps для Android 17).

---

## Что подготовить
1. Компьютер с установленными `adb` и `fastboot`.
2. USB-кабель (желательно подключать в порт USB 2.0 на материнской плате).
3. **Recovery:** Рекомендуется **OrangeFox Recovery R11.1+** с поддержкой Dynamic Partitions (Retrofit) для `ginkgo/willow`.
4. Архив с прошивкой: `BlueOS-0.8.1-ginkgo-*.zip`.

---

## Пошаговая установка

### Шаг 1. Перевод телефона в Fastboot
1. Выключите телефон.
2. Зажмите кнопки **«Громкость вниз»** и **«Питание»**, пока не появится заяц/надпись FASTBOOT.
3. Подключите телефон к компьютеру.

### Шаг 2. Установка Recovery
```bash
fastboot flash recovery recovery.img
fastboot reboot recovery
```
*(При перезагрузке удерживайте кнопку «Громкость вверх», чтобы войти в рекавери).*

### Шаг 3. Очистка (Wipe)
В OrangeFox / TWRP:
1. Перейдите в раздел **Wipe** (Очистка).
2. Выберите **Format Data** и введите `yes` (это снимет шифрование памяти).
3. Затем выберите **Advanced Wipe**: отметьте *Dalvik / ART Cache*, *Cache*, *System*, *Vendor*.
4. Сделайте свайп для очистки.

### Шаг 4. Прошивка BlueOS
1. В рекавери перейдите в **Menu** → **ADB Sideload** (или откройте установку с флешки/MicroSD).
2. На компьютере выполните:
```bash
adb sideload BlueOS-0.8.1-ginkgo.zip
```
3. Дождитесь завершения установки (в консоли статус дойдет до 47%–100%, в рекавери появится сообщение `Success`).

### Шаг 5. Первый запуск
1. В рекавери нажмите **Reboot System**.
2. Первая загрузка BlueOS занимает 2–3 минуты: появится фирменный нимб и анимация загрузки BlueOS.
3. Пройдите первоначальный экран настройки с нимбом.

---

## Обновления
Последующие обновления BlueOS устанавливаются поверх текущей системы **без сброса данных** через `adb sideload` в рекавери.
